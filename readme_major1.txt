Earthquake  Sensor
1) Open Arduino IDE load the code
2) Press boot button on ESP32
3) Wait till the code it gets hard reset
4) Close the Arduino IDE tab
5) Open command Prompt
6) Go to the directory where the AI model trained code is present (Ex: cd major)
7) Run the code (Ex: python realtime_predict.py)
8) The output will be generated
9) Tilt or shake the MPU6050 sensor, the warning will be generated along with buzzer sound
